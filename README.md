# ☕ Bhai-Bhai Coffee App

A simple and interactive **Coffee & Tea Ordering System** built using Python. This project allows customers to explore a menu, add items to their order, view their cart, calculate the total bill, and confirm their checkout.

## 🚀 Features

- ☕ Interactive coffee and tea menu.
- 🛒 Add multiple items to your order.
- 📋 View your complete order summary.
- 💰 Automatic total bill calculation.
- ✅ Simple checkout and order confirmation.
- 🔄 Clear the cart after successful checkout.
- 🔢 Input validation for menu selection.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd Bhai-Bhai-Coffee-App
```

**3. Run the application**

```bash
python coffee.py
```

## 💻 How to Use

1. Run the Python program.
2. Explore the available coffee and tea options.
3. Enter the item number to add it to your order.
4. Select View Order to see your cart.
5. Select Checkout to calculate and confirm your bill.
6. Select Exit to close the application.
